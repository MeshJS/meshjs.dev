## Overview

`BrowserWallet` enables your dApp to connect with users' browser extension wallets following the [CIP-30](https://cips.cardano.org/cip/CIP-30) standard. This provides a consistent interface for wallet discovery, connection, transaction signing, and data queries across all compatible wallets.

**Supported wallets include:** Eternl, Nami, Lace, Flint, Typhon, GeroWallet, and any CIP-30 compliant wallet.

## Quick Start

```tsx
import { BrowserWallet } from "@meshsdk/core";

// 1. Get available wallets on user's device
const wallets = await BrowserWallet.getAvailableWallets();

// 2. Connect to a wallet
const wallet = await BrowserWallet.enable("eternl");

// 3. Get wallet balance
const balance = await wallet.getBalance();

// 4. Get wallet address
const address = await wallet.getChangeAddress();
```

## Wallet Discovery

### getAvailableWallets

Retrieve all CIP-30 compatible wallets installed on the user's device.

```tsx
import { BrowserWallet } from "@meshsdk/core";

const wallets = await BrowserWallet.getAvailableWallets();
```

**Returns:**

```tsx
[
  {
    name: "eternl",
    icon: "data:image/png;base64,...",
    version: "0.1.0"
  },
  {
    name: "nami",
    icon: "data:image/png;base64,...",
    version: "3.0.0"
  }
]
```

| Property | Type | Description |
|----------|------|-------------|
| `name` | `string` | Wallet identifier used for connection |
| `icon` | `string` | Base64-encoded wallet icon for UI display |
| `version` | `string` | Wallet extension version |

---

### getSupportedExtensions

Check which CIP extensions a wallet supports before connecting.

```tsx
const extensions = await BrowserWallet.getSupportedExtensions("eternl");
// Returns: [{ cip: 30 }, { cip: 95 }]
```

## Connection

### enable

Connect to a specific wallet. This prompts the user to grant permission.

```tsx
import { BrowserWallet } from "@meshsdk/core";

const wallet = await BrowserWallet.enable("eternl");
```

**With CIP extensions:**

```tsx
// Enable CIP-95 (governance) support
const wallet = await BrowserWallet.enable("eternl", [95]);
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `walletName` | `string` | Yes | Wallet identifier from `getAvailableWallets()` |
| `extensions` | `number[]` | No | CIP numbers to enable (e.g., `[95]` for governance) |

## UTXOs & Collateral

### getUtxos

Get all unspent transaction outputs controlled by the wallet.

```tsx
const utxos = await wallet.getUtxos();
```

**Returns:**

```tsx
[
  {
    input: {
      txHash: "16dcbb1f93b4f9d5e...",
      outputIndex: 0
    },
    output: {
      address: "addr_test1qz...",
      amount: [
        { unit: "lovelace", quantity: "1314550" },
        { unit: "d9312da562da182b...", quantity: "1" }
      ]
    }
  }
]
```

---

### getCollateral

Get UTXOs suitable for use as collateral in Plutus script transactions.

```tsx
const collateral = await wallet.getCollateral();
```

Collateral UTXOs must contain only ADA (no native assets) and meet minimum value requirements.

## Transaction Operations

### signTx

Sign a transaction with the wallet's private keys.

```tsx
// Single signature
const signedTx = await wallet.signTx(unsignedTx);

// Partial signing (for multi-sig transactions)
const partiallySignedTx = await wallet.signTx(unsignedTx, true);
```

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `tx` | `string` | Yes | Unsigned transaction CBOR hex |
| `partialSign` | `boolean` | No | Set `true` for multi-signature transactions |

---

### submitTx

Submit a signed transaction to the network.

```tsx
const txHash = await wallet.submitTx(signedTx);
// "f4ec9833a3bf95403d395f699bc564938f3419537e7fb5084425d3838a4b6159"
```

---

### signData

Sign arbitrary data using CIP-8 message signing. Useful for authentication and proof of wallet ownership.

```tsx
const signature = await wallet.signData("Hello, Mesh!");
```

**With specific address:**

```tsx
const address = await wallet.getChangeAddress();
const signature = await wallet.signData("Hello, Mesh!", address);
```

**Returns:**

```tsx
{
  signature: "845846a2012...",
  key: "a4010103272006215..."
}
```

See <Link href="/guides/prove-wallet-ownership">Prove Wallet Ownership</Link> to verify signatures server-side.

## Complete Example

```tsx
import { BrowserWallet, MeshTxBuilder, BlockfrostProvider } from "@meshsdk/core";

// Setup provider
const provider = new BlockfrostProvider("<YOUR_API_KEY>");

// Check available wallets
const availableWallets = await BrowserWallet.getAvailableWallets();
console.log("Available wallets:", availableWallets.map(w => w.name));

// Connect to wallet
const wallet = await BrowserWallet.enable("eternl");

// Check connection
const networkId = await wallet.getNetworkId();
console.log("Connected to:", networkId === 0 ? "Testnet" : "Mainnet");

// Get wallet info
const address = await wallet.getChangeAddress();
const balance = await wallet.getLovelace();
console.log(`Address: ${address}`);
console.log(`Balance: ${Number(balance) / 1_000_000} ADA`);

// Build and send transaction
const txBuilder = new MeshTxBuilder({
  fetcher: provider,
  verbose: true,
});

const utxos = await wallet.getUtxos();

const unsignedTx = await txBuilder
  .txOut("addr_test1qz...", [{ unit: "lovelace", quantity: "5000000" }])
  .changeAddress(address)
  .selectUtxosFrom(utxos)
  .complete();

const signedTx = await wallet.signTx(unsignedTx);
const txHash = await wallet.submitTx(signedTx);

console.log(`Transaction submitted: ${txHash}`);
```

## React Integration

For React applications, use the `@meshsdk/react` package for built-in wallet components and hooks.

```tsx
import { CardanoWallet, useWallet } from "@meshsdk/react";

function App() {
  const { connected, wallet } = useWallet();

  return (
    <div>
      <CardanoWallet />
      {connected && <p>Connected!</p>}
    </div>
  );
}
```

## Troubleshooting

### Wallet not appearing in getAvailableWallets()
- Ensure the wallet extension is installed and enabled
- Refresh the page after installing a new wallet
- Check that the wallet is unlocked

### "User rejected the request" error
The user declined the connection or signing prompt. Handle this gracefully:

```tsx
try {
  const wallet = await BrowserWallet.enable("eternl");
} catch (error) {
  if (error.message.includes("rejected")) {
    console.log("User declined connection");
  }
}
```

### "Account not set" error
The wallet is locked or no account is selected. Prompt the user to unlock their wallet.

### Transaction signing fails
- Ensure UTXOs are up to date (call `getUtxos()` before building)
- Verify the transaction has sufficient funds for outputs + fees
- For Plutus transactions, ensure collateral is set

### Multi-signature transaction issues
- Set `partialSign: true` when calling `signTx()`
- Each signer must sign the transaction in sequence
- The final signer can use `partialSign: false`

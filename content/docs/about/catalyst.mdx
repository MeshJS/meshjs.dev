Mesh receives funding through [Project Catalyst](https://projectcatalyst.io/), Cardano's decentralized innovation fund. This page shows our funded proposals and their current progress.

## What is Project Catalyst?

Project Catalyst enables the Cardano community to vote on proposals that improve the ecosystem. Each funding round (called a "Fund") allocates ADA to approved projects. Mesh has received funding across multiple rounds to build and maintain open-source tools for Cardano developers.

## How We Use Funding

Your Catalyst votes support:

- **Core SDK development** - New features, performance improvements, and bug fixes
- **Developer tools** - Transaction builders, smart contract integrations, and debugging utilities
- **Documentation** - Tutorials, guides, and API references
- **Community support** - Discord help, workshops, and live coding sessions
- **Ecosystem projects** - Hydra integration, multi-signature platforms, and developer events

## Overview

`TxBuilder` builds a Cardano transaction from a list of parts, such as `output(...)` or `mint.native(...)`. You name a payer, and the builder selects inputs, adds change and sets the fee; for scripts it also adds collateral and execution units. Then you sign and submit. Examples use `wallet` (a [wallet](/apis/wallets): a `MeshWallet` or `BrowserWallet`) and `recipient` (an address) from your application.

## Quick Start

```tsx
import { BlockfrostProvider, output, TxBuilder } from "@meshsdk/core";

// A provider reads the chain
const provider = new BlockfrostProvider("<YOUR_API_KEY>");
const builder = new TxBuilder({ network: "preprod", provider });

// Build: the builder picks inputs, adds change and sets the fee
const built = await builder.build(
  output({ address: recipient, value: { lovelace: 5_000_000n } }), // 5 ada
  { payer: wallet },
);

await built.sign(); // the payer signs
await built.submit(); // sent through the provider
console.log(built.txHash);
```

`TxBuilder` lives in `@meshsdk/transaction`, and `@meshsdk/core` re-exports it. Amounts are `bigint`. `built.tx` is the unsigned transaction as a hex string (CBOR). For other providers, see [Providers](/providers).

## Which Part for What

| Part | Use it to |
|------|-----------|
| `output`, `metadata`, `message`, `validity`, `guard.pubKey` | send assets, add metadata, set validity, require a signer |
| `mint.native`, `mint.plutus` | mint and burn assets |
| `spend.plutus`, `spend.native`, `referenceInput` | lock and spend at a script, read an output |
| `certificate.*`, `withdrawal.*` | stake, delegate and withdraw rewards |
| `vote`, `proposal.*` | take part in governance |

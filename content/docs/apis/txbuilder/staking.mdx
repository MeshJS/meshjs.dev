## Overview

Staking uses certificates and withdrawals, passed as parts to `builder.build()`.

Examples stop at `build()`: call `built.sign()` and `built.submit()` as in [Transaction Basics](/apis/txbuilder/basics#build-sign-and-submit). They use `builder` and `wallet` from there, and these names, which your application defines:

- `rewardAddress` - your stake address (`stake_test1...` on a test network, `stake1...` on mainnet)
- `poolId` - a pool id (`pool1...`)
- `stakeScript` - a Plutus staking script, `{ code, version }`
- `operatorKeyHash`, `vrfKeyHash`, `ownerKeyHash`, `metadataHash` - the values of your pool
- `operatorKey`, `epoch` - the pool's cold signing key and the retirement epoch

| Task | Part | Signed by |
|------|------|-----------|
| Register a stake key | `certificate.stakeRegistration` | the stake key |
| Delegate to a pool | `certificate.stakeDelegation` | the stake key |
| Withdraw rewards | `withdrawal.pubKey` | the stake key |
| Deregister a stake key | `certificate.stakeDeregistration` | the stake key |
| Register a pool | `certificate.poolRegistration` | the operator and owner keys |
| Retire a pool | `certificate.poolRetirement` | the operator key |

## Register and Delegate

A stake key must be registered before it can delegate. List both certificates to do it in one transaction: they keep the order you give them. The deposit is the `keyDeposit` protocol parameter unless you pass `deposit`. `pool` is a bech32 pool id or the operator key hash.

```tsx
import { certificate } from "@meshsdk/core";

const built = await builder.build(
  [
    certificate.stakeRegistration({ stake: rewardAddress }),
    certificate.stakeDelegation({ stake: rewardAddress, pool: poolId }),
  ],
  { payer: wallet },
);
await built.sign(); // the payer signs; the stake key too, if the wallet holds it
await built.submit();
await built.awaitInclusion(); // waits until a block holds it
```

If the wallet does not hold the stake key, pass the key as a signer: `built.sign({ signers: [wallet, keySigner(<signing key>)] })`. `built.missing` lists the keys that have not signed yet. `certificate.stakeDelegation` alone changes the delegation of a registered key, and `certificate.stakeRegistrationAndDelegation` does both in one certificate.

## Withdraw Rewards

`amount` is the whole reward balance as a `bigint`. Use `"all"` to let the builder look it up through the provider.

```tsx
import { withdrawal } from "@meshsdk/core";

const built = await builder.build(
  withdrawal.pubKey({ rewardAddress, amount: "all" }),
  { payer: wallet },
);
```

To state the amount yourself, write `amount: 5_000_000n`. It must equal the whole balance.

## Deregister a Stake Key

Deregistering refunds the deposit, which defaults to `keyDeposit`. Pass `refund` if the deposit paid was another amount. The reward balance must be empty, so withdraw it in the same transaction.

```tsx
import { certificate, withdrawal } from "@meshsdk/core";

const built = await builder.build(
  [
    withdrawal.pubKey({ rewardAddress, amount: "all" }),
    certificate.stakeDeregistration({ stake: rewardAddress }),
  ],
  { payer: wallet },
);
```

## Withdraw from a Script

A stake address can be held by a Plutus script. Use `withdrawal.plutus` with the script and a redeemer (the data you give the script). Leave out `rewardAddress` and the builder derives the script's own address. An amount of `0n` runs the script without taking rewards, and works only while the reward balance is zero. To run the script whatever the balance, use `amount: "all"`.

A certificate of a script's stake address takes the script as its `witness`: `{ plutus, redeemer }`, which must be V3, or `{ native }`. For a native script, withdraw with `withdrawal.native`.

```tsx
import { certificate, mConStr0, withdrawal } from "@meshsdk/core";

const redeemer = { data: mConStr0([]) };

const built = await builder.build(
  [
    withdrawal.plutus({ script: stakeScript, redeemer, amount: "all" }),
    certificate.stakeDelegation({
      stake: builder.rewardAddress(stakeScript),
      pool: poolId,
      witness: { plutus: stakeScript, redeemer },
    }),
  ],
  { payer: wallet },
);
```

The script's stake address must be registered first, with `certificate.stakeRegistration` and the same `witness`.

## Register a Pool

A stake pool operator registers a pool with `certificate.poolRegistration`. `pledge` and `cost` are lovelace as text. `margin` is `[numerator, denominator]`. The operator and owner keys sign, so pass the operator key as a signer. A first registration pays the pool deposit. To update a pool that is already registered, list its operator key hash in the `registeredPools` option of `build()`, and no deposit is owed.

```tsx
import { certificate, keySigner } from "@meshsdk/core";

const built = await builder.build(
  certificate.poolRegistration({
    params: {
      operator: operatorKeyHash,
      vrfKeyHash,
      pledge: "500000000",
      cost: "340000000",
      margin: [3, 100],
      owners: [ownerKeyHash],
      rewardAddress,
      relays: [{ type: "SingleHostName", domainName: "relay.example.com", port: 3001 }],
      metadata: { URL: "https://example.com/pool.json", hash: metadataHash },
    },
  }),
  { payer: wallet },
);
await built.sign({ signers: [wallet, keySigner(operatorKey)] });
```

To retire the pool, use `certificate.poolRetirement({ pool: poolId, epoch })`. The pool retires at the start of that epoch, and the operator key signs, as above.

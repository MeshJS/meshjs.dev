Mesh Wallet provides programmatic access to wallet functionality without requiring a browser extension. Use it for minting scripts, automated transactions, multi-signature coordination, and any scenario where your application needs to sign transactions directly.

## Installation

```bash
npm install @meshsdk/core
```

## Quick Start

```tsx
import { MeshWallet, MaestroProvider } from '@meshsdk/core';

// 1. Set up a provider
const provider = new MaestroProvider({
  network: 'Preprod',
  apiKey: '<Your-API-Key>'
});

// 2. Create wallet with mnemonic
const wallet = new MeshWallet({
  networkId: 0,
  fetcher: provider,
  submitter: provider,
  key: {
    type: 'mnemonic',
    words: ['solution', 'solution', '...'] // 24 words
  }
});

// 3. Initialize and use
await wallet.init();
const address = wallet.getChangeAddress();
const balance = await wallet.getBalance();
```

## Initialize Wallet

Create a Mesh Wallet instance with a provider and key configuration. The provider handles blockchain queries and transaction submission.

### Key Types

Mesh Wallet supports four key types:

| Key Type | Description | Signing | Use Case |
|----------|-------------|---------|----------|
| Mnemonic | 24-word recovery phrase | Yes | Standard wallets |
| Private Key | Root private key (bech32) | Yes | Advanced integrations |
| CLI Keys | Cardano CLI generated skeys | Yes | Node operators |
| Address | Read-only wallet | No | Balance monitoring |

#### Mnemonic Phrases

The most common initialization method using a BIP39 recovery phrase:

```tsx
const wallet = new MeshWallet({
  networkId: 0, // 0: testnet, 1: mainnet
  fetcher: provider,
  submitter: provider,
  key: {
    type: 'mnemonic',
    words: [
      "solution", "solution", "solution", "solution",
      "solution", "solution", "solution", "solution",
      "solution", "solution", "solution", "solution",
      "solution", "solution", "solution", "solution",
      "solution", "solution", "solution", "solution",
      "solution", "solution", "solution", "solution"
    ]
  }
});
```

#### Private Keys

Initialize with a root private key in bech32 format:

```tsx
const wallet = new MeshWallet({
  networkId: 0,
  fetcher: provider,
  submitter: provider,
  key: {
    type: 'root',
    bech32: 'xprv1cqa46gk29plgkg98upclnjv5t425fcpl4rgf9mq2txdxuga7jfq...'
  }
});
```

#### Cardano CLI Keys

Use keys generated by Cardano CLI. Extract the `cborHex` from your `signing.skey` file:

```tsx
const wallet = new MeshWallet({
  networkId: 0,
  fetcher: provider,
  submitter: provider,
  key: {
    type: 'cli',
    payment: '5820aaca553a7b95b38b5d9b82a5daa7a27ac8e34f3cf27152a978f4576520dd6503',
    stake: '582097c458f19a3111c3b965220b1bef7d548fd75bc140a7f0a4f080e03cce604f0e' // Optional
  }
});
```

> **Note:** Without a stake key, you cannot sign staking transactions.

#### Address (Read-Only)

Create a wallet that can query balances but cannot sign transactions:

```tsx
const wallet = new MeshWallet({
  networkId: 0,
  fetcher: provider,
  key: {
    type: 'address',
    address: 'addr_test1qpvx0sacufuypa2k4sngk7q40zc5c4npl337uusdh64kv0...'
  }
});
```

### Initialize the Wallet

After creating the wallet, call `init()` to load the cryptography library:

```tsx
await wallet.init();
```

## Generate New Wallet

Create a new wallet with a fresh mnemonic phrase:

```tsx
// Generate 24-word mnemonic
const mnemonic = MeshWallet.brew();
console.log(mnemonic); // ['word1', 'word2', ...]

// Or generate a private key directly
const privateKey = MeshWallet.brew(true);
```

> **Important:** Store generated mnemonics securely. Anyone with access to these words can control the wallet.

## Query Wallet Data

### Get Balance

Retrieve all assets in the wallet:

```tsx
const balance = await wallet.getBalance();
```

**Response:**
```tsx
[
  { "unit": "lovelace", "quantity": "796105407" },
  { "unit": "9c8e9da7f81e3ca90485f32ebefc98137c8ac260a072a00c4aaf142d4d657368546f6b656e", "quantity": "2" }
]
```

### Get Lovelace Balance

Get only the ADA balance (in lovelace):

```tsx
const lovelace = await wallet.getLovelace();
// "796105407" (1 ADA = 1,000,000 lovelace)
```

### Get Assets

Retrieve all non-ADA assets:

```tsx
const assets = await wallet.getAssets();
```

**Response:**
```tsx
[
  {
    "unit": "9c8e9da7f81e3ca90485f32ebefc98137c8ac260a072a00c4aaf142d4d657368546f6b656e",
    "policyId": "9c8e9da7f81e3ca90485f32ebefc98137c8ac260a072a00c4aaf142d",
    "assetName": "MeshToken",
    "fingerprint": "asset177e7535dclmkkph8ewt9fsghllkwmpspa3n98p",
    "quantity": "10"
  }
]
```

### Get UTXOs

List all unspent transaction outputs:

```tsx
const utxos = await wallet.getUtxos();
```

**Response:**

## Address Management

### Get Change Address

The address where transaction change is sent:

```tsx
const changeAddress = await wallet.getChangeAddress();
```

### Get Used Addresses

Addresses that have received transactions:

```tsx
const usedAddresses = wallet.getUsedAddresses();
```

### Get Unused Addresses

Fresh addresses for new transactions:

```tsx
const unusedAddresses = wallet.getUnusedAddresses();
```

### Get Reward Addresses

Stake addresses for staking rewards:

```tsx
const rewardAddresses = wallet.getRewardAddresses();
// ["stake_test1uzx0ksy9f4qnj2mzfdncqyjy84sszh64w43853nug5pedjgytgke9"]
```

### Get Network ID

Check if the wallet is on testnet or mainnet:

```tsx
const networkId = wallet.getNetworkId();
// 0 = Testnet, 1 = Mainnet
```

## Transaction Operations

### Sign a Transaction

Sign an unsigned transaction:

```tsx
const signedTx = await wallet.signTx(unsignedTx);

// For partial signing (multi-sig scenarios)
const partiallySignedTx = await wallet.signTx(unsignedTx, true);
```

### Submit a Transaction

Submit a signed transaction to the network:

```tsx
const txHash = await wallet.submitTx(signedTx);
console.log(`Transaction submitted: ${txHash}`);
```

### Sign Data

Sign arbitrary data for authentication or verification:

```tsx
const signature = await wallet.signData('mesh');
```

**Response:**
```tsx
{
  "signature": "845846a2012...f9119a18e8977d436385cecb08",
  "key": "a4010103272006215...b81a7f6ed4fa29cc7b33186c"
}
```

Verify signatures using the [wallet ownership guide](https://meshjs.dev/guides/prove-wallet-ownership#server-verify-signature).

## Collateral Management

### Get Collateral UTXOs

Retrieve UTXOs suitable for Plutus script collateral:

```tsx
const collateralUtxos = await wallet.getCollateral();
```

Collateral UTXOs must be pure ADA (no tokens) and meet minimum value requirements.

### Create Collateral UTXO

Create a dedicated collateral UTXO for smart contract interactions:

```tsx
const txHash = await wallet.createCollateral();
```

## Policy and Collection Queries

### Get Policy IDs

List all policy IDs from assets in the wallet:

```tsx
const policyIds = await wallet.getPolicyIds();
// ["0f5560dbc05282e05507aedb02d823d9d9f0e583cce579b81f9d1cd8", ...]
```

### Get Assets by Policy ID

Retrieve all assets belonging to a specific policy:

```tsx
const collection = await wallet.getPolicyIdAssets(
  'd9312da562da182b02322fd8acb536f37eb9d29fba7c49dc17255527'
);
```

## API Reference

| Method | Returns | Description |
|--------|---------|-------------|
| `init()` | `Promise<void>` | Initialize cryptography library |
| `getBalance()` | `Promise<Asset[]>` | All assets including ADA |
| `getLovelace()` | `Promise<string>` | ADA balance in lovelace |
| `getAssets()` | `Promise<Asset[]>` | Non-ADA assets only |
| `getUtxos()` | `Promise<UTxO[]>` | Unspent transaction outputs |
| `getChangeAddress()` | `Promise<string>` | Change address |
| `getUsedAddresses()` | `string[]` | Previously used addresses |
| `getUnusedAddresses()` | `string[]` | Fresh addresses |
| `getRewardAddresses()` | `string[]` | Stake addresses |
| `getCollateral()` | `Promise<UTxO[]>` | Collateral UTXOs |
| `getNetworkId()` | `number` | Network (0=testnet, 1=mainnet) |
| `getPolicyIds()` | `Promise<string[]>` | All policy IDs |
| `getPolicyIdAssets()` | `Promise<Asset[]>` | Assets by policy |
| `signTx()` | `Promise<string>` | Sign transaction |
| `submitTx()` | `Promise<string>` | Submit transaction |
| `signData()` | `Promise<DataSignature>` | Sign arbitrary data |
| `createCollateral()` | `Promise<string>` | Create collateral UTXO |
| `getDRep()` | `Promise<DRep>` | DRep credentials |
